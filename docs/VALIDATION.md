## Verified in the development workspace

- Checked the overlay's trailing `ULTR` signature, NRO headers, NSP PFS0 entries, NSO header and NPDM program ID during packaging. Toolbox metadata is also validated against that ID and must declare live load/unload support.
- The 101 backend tests exercise admin-only account creation, cookie CSRF/origin checks, password/session revocation, encrypted per-user library isolation, single-use MusicKit linking, native session expiry, Apple-link expiry without backend logout, catalog access without linking, persistence across restarts, and pagination, input validation, official Apple request headers, sanitized resource output, library-to-catalog resolution, keyless syncedlyrics lookup, LRC timestamps, M3U8 byte-range manifests, codec-preserving host remuxing, transient cache limits, HTTP byte ranges, serialized cache preparation, failure cleanup and cache budget eviction. Upstreams are mocked; these tests do not claim live account validation.
- Apple Music QR tests cover same-account/session restrictions, CSRF, quiet borders, hashed capabilities, single-use completion, expiry/cancellation/replacement, in-flight cancellation before token storage, nonce downgrade prevention and legacy database migration. A separate QR decoder verifies the server-generated matrix. Cryptographic tests verify ES256 signatures, origin binding, expiry and rejected-token handling. Browser-flow contract tests verify exact developer JWT configuration, direct-click authorization, Music User Token handoff and ordinary web linking using fake MusicKit/DOM; no live Apple account is contacted.
- The native libcurl integration test exercises password login, session-cookie capture, saved-session reuse, revocation, expiry, logout, URL validation, migration without persisting passwords or CA paths, and authenticated CSRF-protected QR POST requests.
- Packaging verifies the identical CA bundle and its MPL license inside the NRO and certificate-only sysmodule RomFS. The bundle loads as 118 CA certificates through Python/OpenSSL.
- The actual production decoder/custom AVIO executes over authenticated HTTP for AAC, AAC-web, ALAC and 24-bit/192-kHz ALAC. PCM matches reference decoding within one quantization step; seek output matches the corresponding full-decoded PCM suffix. Tests cover EOF draining, cancellation, expired authorization, external URL rejection, full-response/chunked streaming fallback for servers ignoring Range, 600 KiB metadata, 3 GiB virtual-media seeks, large/CRLF manifests, and precise HTTP/transport errors. Tracked static-library allocations remain under the 8 MiB host guard; shared host-library allocations and Horizon services are not a hardware peak measurement.
- A simulated audout service tests PCM ownership/recycling, pause/resume with both cumulative and reset-on-start sample counters, flush/seek and EOF draining. This does not substitute for Horizon playback.
- Packaging enforces a 22 MB linked-image-plus-4-MiB planning cap on the actual NSO and exports its memory report. The sysmodule link contains no mpv symbols.
- Host C++ IPC payload tests cover JSON round trips, malformed object rejection, exact 64 KiB bounds, oversized replies, protocol version/type checks, revoked/empty session rejection and URL escaping. Switch builds compile the actual CMIF client, named-port server, NRO and overlay. These host tests do not execute Horizon kernel IPC.
- Built the pinned Gamdl Rust/Python package under Python 3.12 and imported the adapter's API/model/stream classes. Its 17 synthetic wrapper-v2 TCP/fMP4 fixture tests passed.
- Built the backend Docker image and smoke-tested non-root startup, a read-only root filesystem, native playback imports, HTTP health, unauthenticated route rejection, packaged web assets, account creation and account/session persistence across container restarts. Docker Compose configuration also parsed successfully.

The SDK here was missing GLM and libjpeg. They were built/staged under `/tmp` for validation; the installed devkitPro tree was not changed. Normal builds should install `switch-glm` and `switch-libjpeg-turbo`. The JPEG test build used PIC and the Switch ARMv8/soft-TLS ABI flags. Host packages must not enter the Switch pkg-config search path.

## Current behavior and limits

Multiple local accounts with optional per-user Apple library links, public catalog search, read-only library browsing, shared host wrapper playback, bounded queue history, backend preparation latency, and no gapless/prefetch/shuffle/repeat/offline library. Track/list covers and the overlay now use backend-prepared artwork. The web UI could not be visually checked because the browser automation host was unavailable; HTTP/static asset behavior is covered by tests. Uploaded library tracks without catalog matches and music videos are unavailable. No Apple authentication secrets are shipped with the project, and live service operation requires your host configuration and account entitlements.

Guest catalog checks cover anonymous search, album/playlist track pagination, absence of personal Apple tokens, and protected library/resolution endpoints. The native libcurl integration also saves/reloads URL-only guest configuration and performs an anonymous catalog request, while rejecting guest login/session-required validation. Verify the guest NRO screens, keyboard search and collection navigation on hardware.

Static playback URL regression checks cover anonymous manifests and byte ranges, expired-cookie independence, warm cache hits without Apple calls, existing cache files after restart, eviction of audio and playlist together, and automatic regeneration through both manifest and direct-media requests.

The XML UI is cross-compiled for Switch and exercised using desktop Borealis/SDL2 with the production NRO controller class and synthetic loopback data. All static screens and repeated row templates are parsed/rendered, including long titles, empty collections, settings and QR linking. Controller checks cover sidebar/content transitions, X Search, B return, collection history, selected-row restoration and guest-only library visibility. Screenshots are actual OpenGL framebuffer captures; no Apple account is contacted. Physical Switch rendering, keyboard, touchscreen and Joy-Con acceptance checks remain necessary.

For the Horizon IPC migration, verify on hardware that NRO and overlay state/commands work together, unavailable modules report promptly, Toolbox disable/re-enable permits reconnection, and logout/relogin rejects old session requests. Exercise malformed CMIF descriptors, rapid session opens/closes and idle session expiry with a device test client. The overlay has no socket initialization; NRO/sysmodule sockets remain for backend HTTP only.

The full-response streaming fixture verifies a single HTTP connection serves sequential reads across multiple 256 KiB windows; backward seek starts a second request. AAC, AAC-web, ALAC and 192 kHz ALAC PCM/seek comparisons pass through both normal HTTP ranges and full-file response fallback. The 8 MiB allocator guard remains test instrumentation, not a production refusal threshold. Actual Horizon runtime peak and playback against the deployed proxy still need hardware verification.

Artwork tests verify thumbnail dimensions, RGBA4444 nibble ordering, cache hits, absence of Apple credentials on CDN requests, blocked non-Apple artwork hosts, and personal-library isolation even with warm caches. A native fixture executes the production background artwork worker and IPC chunk assembler, including stale tracks, replacement/cancellation, malformed pixels and message-size bounds. Desktop Borealis tests render loaded thumbnails and assert their position between order number and title. The native overlay compiles; its physical rendering, touch and controller behavior still require Switch acceptance testing.

The Atmosphère crash with build ID `3738e33b2e73732431a3bace844dac6c98ac9191` was symbolized against the matching ELF: PC `+0x171fd8` is `memcpy`, called by the IPC reply write at `+0x2e534`. The reported destination is null and TLS contains a filesystem service reply. A host kernel/TLS test double now executes the production `control_ipc.cpp` server loop, overwrites TLS during a simulated nested filesystem request, and validates the resulting reply. The pre-fix source reproduces the null write under AddressSanitizer/UBSan; the fixed source passes, along with malformed-header and short-output tests.
