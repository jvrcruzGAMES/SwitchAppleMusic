# Validation

## Verified in the development workspace

- Cross-compiled and linked `SwitchMusic.nro`, `switchmusic.ovl`, and `switchmusic-sys.nsp` using devkitA64 GCC 16.1.0 and the installed libnx/portlibs.
- Checked the overlay's trailing `ULTR` signature, NRO headers, NSP PFS0 entries, NSO header and NPDM program ID during packaging. Toolbox metadata is also validated against that ID and must declare live load/unload support.
- The 79 backend tests exercise admin-only account creation, cookie CSRF/origin checks, password/session revocation, encrypted per-user library isolation, single-use MusicKit linking, native session expiry, Apple-link expiry without backend logout, catalog access without linking, persistence across restarts, and pagination, input validation, official Apple request headers, sanitized resource output, library-to-catalog resolution, keyless syncedlyrics lookup, LRC timestamps, M3U8 byte-range manifests, codec-preserving host remuxing, transient cache limits, HTTP byte ranges, serialized cache preparation, failure cleanup and cache budget eviction. Upstreams are mocked; these tests do not claim live account validation.
- Apple Music QR tests cover same-account/session restrictions, CSRF, quiet borders, hashed capabilities, single-use completion, expiry/cancellation/replacement, in-flight cancellation before token storage, nonce downgrade prevention and legacy database migration. A separate QR decoder verifies the server-generated matrix. Browser-flow contract tests verify click-gesture authorization and unchanged ordinary web linking using fake MusicKit/DOM; no live Apple account is contacted.
- The native libcurl integration test exercises password login, session-cookie capture, saved-session reuse, revocation, expiry, logout, URL validation, migration without persisting passwords or CA paths, and authenticated CSRF-protected QR POST requests.
- Packaging verifies the identical CA bundle and its MPL license inside the NRO and certificate-only sysmodule RomFS. The bundle loads as 118 CA certificates through Python/OpenSSL.
- The actual production decoder/custom AVIO executes over authenticated HTTP for AAC, AAC-web, ALAC and 24-bit/192-kHz ALAC. PCM matches reference decoding within one quantization step; seek output matches the corresponding full-decoded PCM suffix. Tests cover EOF draining, cancellation, expired authorization, external URL rejection and servers ignoring Range. Tracked static-library allocations remain under the 8 MiB host guard; shared host-library allocations and Horizon services are not a hardware peak measurement.
- A simulated audout service tests PCM ownership/recycling, pause/resume with both cumulative and reset-on-start sample counters, flush/seek and EOF draining. This does not substitute for Horizon playback.
- Packaging enforces a 22 MB linked-image-plus-4-MiB planning cap on the actual NSO and exports its memory report. The sysmodule link contains no mpv symbols.
- Host C++ framing test covers round trips, fragmented frames, invalid JSON, maximum size enforcement and URL escaping.
- Built the pinned Gamdl Rust/Python package under Python 3.12 and imported the adapter's API/model/stream classes. Its 17 synthetic wrapper-v2 TCP/fMP4 fixture tests passed.
- Built the backend Docker image and smoke-tested non-root startup, a read-only root filesystem, native playback imports, HTTP health, unauthenticated route rejection, packaged web assets, account creation and account/session persistence across container restarts. Docker Compose configuration also parsed successfully.

The SDK here was missing GLM and libjpeg. They were built/staged under `/tmp` for validation; the installed devkitPro tree was not changed. Normal builds should install `switch-glm` and `switch-libjpeg-turbo`. The JPEG test build used PIC and the Switch ARMv8/soft-TLS ABI flags. Host packages must not enter the Switch pkg-config search path.

## Current behavior and limits

Multiple local accounts with optional per-user Apple library links, public catalog search, read-only library browsing, shared host wrapper playback, bounded queue history, backend preparation latency, and no gapless/prefetch/shuffle/repeat/offline library. Album art is not implemented. The web UI could not be visually checked because the browser automation host was unavailable; HTTP/static asset behavior is covered by tests. Uploaded library tracks without catalog matches and music videos are unavailable. No Apple authentication secrets are shipped with the project, and live service operation requires your host configuration and account entitlements.
